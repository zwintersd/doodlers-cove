# Doodler's Cove - Assets Manifest

A comprehensive guide to all visual assets needed for the game. All assets should follow the **soft pastel, flat color, no glow, minimal animation** aesthetic inspired by Care Bears and Dragon Tales with retro web vibes.

---

## Style Guidelines

- **Colors**: Soft, muted pastels only. No saturated or bright colors.
- **Style**: Flat colors, no gradients, no glow effects, no drop shadows
- **Lines**: Simple outlines (2-3px), slightly rounded
- **Animation**: Minimal - simple 2-3 frame loops if any
- **Format**: PNG with transparency (or SVG for icons)
- **Aesthetic**: Retro web (90s/2000s internet), storybook illustration

## Notes for Artists

1. **Keep it simple** - These should feel like they could be drawn with crayons or colored pencils
2. **Consistency** - All assets should feel like they belong in the same world
3. **No harsh edges** - Soft, rounded shapes throughout
4. **Readable at small sizes** - Icons need to be recognizable at 32x32
5. **Care Bear meets Stardew** - Cute, wholesome, magical farming vibes
6. **Dragon Tales warmth** - Friendly, approachable, childlike wonder
7. **Retro web charm** - Think Neopets, old web graphics, simple and charming

The game currently uses ASCII/emoji placeholders that work without assets, so take your time making these feel right!
