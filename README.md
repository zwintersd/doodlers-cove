# Doodler's Cove

A magical incremental clicker game with Care Bear and Dragon Tales inspiration. Gather stardust, befriend magical creatures, and explore enchanted lands.

## Features

- **Magical Resources**: Collect stardust, rainbow drops, dream seeds, moonbeams, heart gems, cloud fluff, and wish petals
- **Cute Creatures**: Befriend sparkle bunnies, cloud sheep, rainbow birds, moon moths, heart bears, and wish dragons
- **Enchanted Areas**: Explore Starlight Meadow, Rainbow Falls, Dream Garden, and Heart Crystal Cave
- **Upgrades**: Purchase magical upgrades to boost your gathering abilities
- **Auto-Save**: Progress saves automatically to local storage

## Style

- Soft pastel, flat colors
- No glow effects, minimal animation
- Retro web aesthetics
- Stardew Valley-inspired resources with a more magical twist

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
